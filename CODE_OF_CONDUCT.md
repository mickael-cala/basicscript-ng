# Code de conduite — contributeurs

## Notre engagement

Dans le but de favoriser un environnement ouvert et accueillant, nous, contributeurs et mainteneurs, nous engageons à faire de la participation à ce projet une expérience exempte de harcèlement pour tout le monde, indépendamment du niveau d'expérience, du genre, de l'orientation sexuelle, du handicap, de l'apparence physique, de la taille, de la race, de l'origine ethnique, de l'âge, de la religion ou de l'identité sexuelle.

## Nos standards

Exemples de comportement qui contribue à créer un environnement positif :

* Utiliser un langage accueilant et inclusif ;
* Respecter les points de vue différents ;
* Accepter les critiques constructives ;
* Se concentrer sur ce qui est le mieux pour le projet ;
* Faire preuve d'empathie envers les autres membres du projet.

Exemples de comportement inacceptable :

* L'utilisation de langage sexualisé et les avances non sollicitées ;
* Le trolling, les commentaires insultants ou péjoratifs, et les attaques personnelles ou politiques ;
* Le harcèlement public ou privé ;
* La publication d'informations privées telles que l'adresse physique ou électronique d'une personne sans son autorisation explicite ;
* Tout autre contexte qui pourrait être considéré comme non professionnel.

## Responsabilités des mainteneurs

Les mainteneurs du projet sont responsables de clarifier la norme de comportement acceptable et sont censés prendre des mesures correctives justes et appropriées en réponse à tout cas de comportement inacceptable, y compris le retrait temporaire ou permanent de tout contributeur dont les comportements violent ce code de conduite.

## Portée

Ce code de conduite s'applique dans tous les espaces du projet ainsi que dans les espaces publics lorsqu'un individu représente le projet (forum, e-mail, réseaux sociaux, événement officiel ou non).

## Application

Les comportements abusifs, harcelants ou tout autre comportement inacceptable peuvent être signalés en contactant l'équipe du projet via une issue GitHub ou l'adresse du dépôt. Toutes les plaintes seront examinées et résolues de manière juste et proportionnée. Les mainteneurs sont tenus de respecter la confidentialité vis-à-vis du rapporteur d'un incident.
